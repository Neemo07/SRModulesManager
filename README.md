# Silkroad Module Manager

Straight-forward silkroad modules(executable) manager and monitor, it doesn't communicate with silkroad its just monitoring processes, no fancy packets shits!

SR_Manager.ini
```

Path=C:\Users\xxx\Source\Repos\ISRORCert-master\src\ISRORCert\bin\Debug\net6.0
[Billing]
Path=C:\Users\xxx\Source\Repos\ISRORBilling\bin\Debug\net7.0
[Common]
Path=H:\SILKROADR\SRO_Server
[AgentServer]
Count=2
Path1=H:\SILKROADR\SRO_Server\ASGS\AgentServer1
Path2=H:\SILKROADR\SRO_Server\ASGS\AgentServer2
[ShardManager]
Count=1
Path1=H:\SILKROADR\SRO_Server
[GameServer]

Path2=H:\SILKROADR\SRO_Server\ASGS\GameServer2
```
